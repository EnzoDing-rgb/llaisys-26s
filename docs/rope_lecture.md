# 任务 2.5：旋转位置编码（RoPE）讲义

> 假设你几乎是从零开始。先把「为什么要有 RoPE」讲透，再回答「为什么公式里除了 $p_i$ 还有 $j$、$\theta$、$d$」，最后落到本作业怎么算。

---

## 1. RoPE 为什么存在？

注意力在干什么：每个位置有 $q$，每个位置有 $k$，用内积打分。内积更大，就更关注那里。内积天生只看「向量像不像」，**不会自动**看「谁排在谁前面」。

### 1.1 如果没有位置处理，我们看到什么问题？

```text
位置 0：「猫」→  q0 = (1, 0)，  k0 = (1, 0)
位置 1：「狗」→  q1 = (1, 0)，  k1 = (1, 0)
```

站在位置 0：

$$
q0 \cdot k0 = 1,\qquad q0 \cdot k1 = 1
$$

「看自己」和「看狗」分数一样。语言里词序往往改变意义，可是这里 **词序进不了打分**。

### 1.2 有了按位置旋转之后，为什么能修好？

想法：做内积**之前**，按位置编号 $p$ 把该处的 $q$、$k$ 转一下。位置不同 → 转角不同 → 内积随相对位置变化。

为好算，暂令位置 $p$ 转 $p\cdot 90^\circ$：位置 0 仍是 $(1,0)$，位置 1 转到 $(0,1)$。则

$$
q0'\cdot k0' = 1,\qquad q0'\cdot k1' = 0
$$

分数分开了，因为相对转角进了内积。更一般：位置 $m$、$n$ 的内积依赖 $\phi_m-\phi_n$；让 $\phi$ 随 $p$ 变，内积就依赖相对距离。

**到这里，你已经有了最硬的直觉：要让内积认识词序，就要让角度依赖位置 $p$。**

---

## 2. RoPE 作用在哪？

- sequence 里每个 token 一个位置；
- 每个 token 的某个 head 上有一个长度 $d$ 的 $q$ 或 $k$；
- RoPE 旋转的是这个长度 $d$ 的向量；
- token 之间互看，仍由后面的 attention 做。

---

## 3. 只按 $p_i$ 转，为什么公式里还有 $j$、$\theta$、$d$？

猫狗例子只证明：**角度要依赖 $p$。**  
诡异感通常来自：为什么还要配对、还要 $j$、还要 $\theta$ 和 $d$？下面按步骤建立直觉。

### 3.1 旋转的最小零件是「两个数组成的平面」

几何上，一次旋转发生在平面里：两个坐标转一个角。  
$d$ 个实数分量 → 切成 $d/2$ 个小平面，每个平面自己转。  
「配对」首先只是：**指定哪两个分量构成一个可转的小平面。**

若你愿意，这 $d/2$ 个平面甚至可以共用同一个转角（都只由 $p$ 决定）。猫狗问题在单一尺度上已经能修。

### 3.2 所有平面共用一个频率时，缺的是「多尺度」

假设两个平面都用同一个 $\phi = p\cdot\omega$。  
相对位置仍能进内积，但你只有 **一种节拍**：

- 频率太快：近邻好分辨，绕一圈后和更远的某些差容易糊在一起；
- 频率太慢：远距离有点感觉，近邻 $p$ 与 $p+1$ 几乎转一样多。

语言里的相对距离是多尺度的：既要区分相邻词，也要区分隔得很远的依赖。  
一个频率很难把「隔 1」和「隔 100」都照顾好。

所以设计升级为：

> 每个平面仍由同一个位置 $p_i$ 驱动，但 **每个平面用自己的频率** $\omega_j$：  
> $\phi_{i,j} = p_i \cdot \omega_j$。

- $\omega_j$ 大：位置加 1，角就变很多 → 擅长近距离；
- $\omega_j$ 小：位置要加很多，角才明显变 → 擅长远距离。

这里：

- $p_i$：转到哪一格（你已经熟悉的）；
- $j$：第几路频率、第几根「指针」。

钟表类比（帮助记忆）：慢针看大段，快针看细格；多针合在一起，比单针更能刻画「相对多远」。

### 3.3 $\theta$ 和 $d$：规定这 $d/2$ 路频率怎么从快排到慢

需要一组从快到慢的 $\omega_j$。业界沿用 Transformer 正弦位置编码里那套排法：

$$
\omega_j = \frac{1}{\theta^{2j/d}}
$$

于是本作业公式：

$$
\phi_{i,j} = \frac{p_i}{\theta^{2j/d}}
$$

| 符号 | 角色 |
|------|------|
| $p_i$ | 该 token 的位置 |
| $j$ | 第几路频率 / 第几个平面 |
| $d$ | 头维；决定有多少个平面，也参与频率如何铺开 |
| $\theta$ | 频率铺开用的底数（测试里常取 $10000$），拉开最快与最慢 |

一句话：

> $p_i$ 提供「按位置转」；$j,\theta,d$ 提供「用多路不同快慢一起转」。  
> 猫狗直觉对应前者；你觉得 magic 的部分，多半对应后者。

### 3.4 这是莫名其妙蒙出来的吗？

可以诚实分层：

1. **按位置旋转，好让内积认相对位置** — 动机清楚（猫狗例子）。  
2. **多用几路频率，覆盖近/中/远** — 动机也清楚（多尺度；单频率不够用）。  
3. **频率具体写成 $\theta^{-2j/d}$** — 继承自更早的正弦 PE 的经验公式，RoPE 拿来当旋转角；是传统 + 经验，世上还有别的排法。  
4. **前后对半还是相邻交错来组成平面** — 主要是实现约定；本作业用前后对半。

所以：觉得「$j,\theta,d$ 很诡异」并不丢人——其中确有设计选择；但它们对应的思想可以用「多指针 / 多尺度」建立直觉，而不是纯噪声。

### 3.5 本作业怎么切平面、怎么写回

```text
a = x[0 : d/2]
b = x[d/2 : d]
平面 j: (a[j], b[j]) = (x[j], x[d/2+j])
```

$d=4$：平面 0 转 $(x0,x2)$，平面 1 转 $(x1,x3)$。

$$
a'_{i,j} = a_{i,j}\cos\phi_{i,j} - b_{i,j}\sin\phi_{i,j}
$$

$$
b'_{i,j} = b_{i,j}\cos\phi_{i,j} + a_{i,j}\sin\phi_{i,j}
$$

数字感（$\theta=10000$，$p=2$，$d=4$）：$j=0$ 时 $\phi=2$；$j=1$ 时 $\phi=0.02$。同一位置两路频率差出两个数量级，就是快慢指针在同时干活。

## 4. 接口、测试、实现

```c++
void rope(tensor_t out, tensor_t in, tensor_t pos_ids, float theta);
```

| 参数 | 含义 |
|------|------|
| `in` / `out` | Q 或 K，`[seqlen, nhead, d]`，连续 |
| `pos_ids` | `[seqlen]`，int64，上下文绝对位置 |
| `theta` | 频率基数，测试用 `10000` |

支持 F32 / F16 / BF16；半精度在 float32 里算再写回。  
`pos_ids` 可能从 0 起，也可能从 512 起；角度必须用 `pos_ids[s]`。

```text
for s, h, j:
    phi = pos_ids[s] / theta**(2*j/d)
    按上式写 a'[j], b'[j]
```

自检：`python test/ops/rope.py`。

---

## 5. 收束

1. **没有位置旋转：** 内积只认内容，词序进不了分数。  
2. **有位置旋转：** 相对转角进入内积，词序 / 距离可分。  
3. **只有 $p$ 不够漂亮：** 还要多路频率，才能同时照顾近距离和远距离 → 公式里出现 $j,\theta,d$。  
4. **配对：** 先是「两个分量组成一个旋转平面」；前后对半是本作业的切法约定。
